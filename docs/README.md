# Documentation

This directory contains supplementary documentation and example data for the
Multi-Channel DataLogger.

## Contents

| Directory | Description |
|---|---|
| `data/` | Example measurement data recorded by the datalogger |
| `datasheet/` | Datasheets and technical notes for hardware components |

## Measurement Data

The `data/` directory contains example CSV files generated by the firmware.
These files can be used to verify the data format or for testing data-processing
and visualization tools.

The current firmware records:

- SHT4x temperature and relative humidity
- multiple DS18B20 temperature sensors
- two analog inputs
- battery voltage
- four digital inputs

For the current CSV format and firmware operation, see
[`../firmware/README.md`](../firmware/README.md).

## Hardware Documentation

Component datasheets and related technical notes are stored in
[`datasheet/`](datasheet/).

The KiCad schematic and project-specific hardware documentation are located in
[`../hardware/schematic/`](../hardware/schematic/).
